Mini Project

**Project Overview**
- **Description:** A simple static web project containing a single-page app built with HTML, CSS, and JavaScript. It demonstrates basic structure and interactivity using `index.html`, `style.css`, and `script.js`.

**Features**
- **Static Pages:** Lightweight, no build step required.
- **Client-side Interactivity:** JavaScript-driven behaviors in the browser.

**Files**
- **index.html**: Main HTML entry point — [index.html](index.html).
- **style.css**: Styles for the site — [style.css](style.css).
- **script.js**: Client-side scripts and interactivity — [script.js](script.js).

**Setup**
- **Open Locally:** Double-click [index.html](index.html) to open in your default browser.
- **Run Local Server (optional):** From the project root run:

```bash
# If you have Python 3 installed
python -m http.server 8000
# or on Windows if python is "py"
py -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

**Usage**
- **Navigate:** Use the UI in `index.html`.
- **Modify:** Edit `style.css` to change visuals and `script.js` to change behavior.

**Development Notes**
- **No dependencies:** Pure static files; no package manager required.
- **Testing:** Open in multiple browsers to verify behavior.
